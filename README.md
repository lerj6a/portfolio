# Портфолио Валерии Зайцевой — GitHub Pages

Это готовый статический сайт. Сборка, установка пакетов и локальный сервер для публикации не нужны. Все изображения, GIF и библиотеки анимации находятся в папке assets. Пути относительные: сайт работает и в репозитории вида username.github.io/portfolio/.

## Как опубликовать

1. В GitHub создайте публичный репозиторий, например portfolio.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория: index.html, styles.css, app.js, projects.js и папку assets. Не загружайте ZIP как единственный файл и не помещайте сайт во вложенную папку.
3. Откройте Settings → Pages. В разделе Build and deployment выберите Source → Deploy from a branch, ветку main и папку / (root). Нажмите Save.
4. Дождитесь успешного развёртывания. Адрес появится в Settings → Pages: https://ВАШ-ЛОГИН.github.io/portfolio/.
5. Этот адрес можно отправлять другим людям. localhost и 127.0.0.1 работают только на вашем компьютере.

Если загрузка через браузер ограничивает число файлов, загружайте assets отдельными подпапками, сохраняя структуру. Все файлы в комплекте меньше 25 МБ.

## Что редактировать

- index.html — разделы страницы, опыт, образование и контакты.
- projects.js — названия и описания кейсов, порядок проектов.
- styles.css — оформление и адаптив.
- app.js — карточки, галереи, навигация и анимации.
- assets — изображения, анимации и логотипы.

При обновлении заменяйте нужные файлы и фиксируйте изменения в GitHub. Публикация обновится автоматически. Не меняйте имена файлов и подпапок без изменения ссылок в коде.

Комплект проверен: синтаксис JavaScript, генерация восьми кейсов и наличие всех локальных изображений и зависимостей. Публикация в GitHub ещё не выполнена — она требует вашего репозитория.
